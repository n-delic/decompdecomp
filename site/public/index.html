Agents decompile your game.

Open a game you own in the app and start helper agents. They write C or C++, one function at a time. The game's original compiler builds each attempt, and only identical bytes count.

How it's checked

The game's compiler is the judge. Not the AI.

Each attempt is compiled with the same compiler and flags the game was built with, linked at the function's real address, and compared with your copy. A near miss comes back with an instruction diff. Only score 0 is a match.

From your ROM 0x800007D0

slt     $v0, $a0, $a1
bnez    $v0, .L800007EC
 addu   $v0, $a1, $zero
addu    $v0, $a2, $zero
slt     $v1, $v0, $a0
beql    $v1, $zero, .L800007EC
 addu   $v0, $a0, $zero
.L800007EC:
jr      $ra
 nop

From the agent clamp_s32.c

s32 clamp_s32(s32 v, s32 lo, s32 hi) {
    if (v < lo) {
        return lo;
    }
    if (v > hi) {
        return hi;
    }
    return v;
}

score 0 36 of 36 bytes identical, built with KMC GCC 2.7.2 -O2

Yours.

  1. Your game stays on your computer. No account, no telemetry, nothing uploaded. decompdecomp supplies no games.
  2. Your agents do the work: any model with an API key, Claude Code, Codex, opencode or Antigravity CLI. The app starts them and restarts them. You pay your own provider.
  3. Your code comes out as a project that builds your game again, byte for byte: the start of a port or a mod.

The code from a game belongs to its rights holder. Keep it to yourself.

Start.

1 · Install

curl -fsSL https://decomp.ndelic.com/install.sh | bash

Linux, or Windows 10 and 11 through WSL 2: run it in your WSL terminal (Ubuntu, for example). It installs the app and compilers, then opens the app in its own window. There's also a .deb, an .rpm and an AppImage on the releases page.

curl -fsSL https://decomp.ndelic.com/install.sh | bash -s -- --source branch:main

macOS 12+ on Intel and Apple Silicon: installs the current source and a Finder app in ~/Applications. Apple Silicon needs Rosetta for the Intel N64 KMC compiler and binutils. PS1/PS2 period compilers need Linux; macOS has no menu bar tray icon yet.

2 · Open your game

Pick your own copy of the game in the app, then click Start agents: any model with an API key, Claude Code, Codex, opencode or Antigravity CLI. Run several: they work on different functions at the same time. Or open Demo Quest 64 and watch first.

decompdecomp continues decomp.wtf by Sam Wolfs. It is built on splat, spimdisasm, objdiff, decomp-toolkit, m2c, Ghidra, decomp-permuter, wibo and the decompals compilers.
