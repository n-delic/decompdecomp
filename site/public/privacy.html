Privacy

This website

This website has no cookies, no analytics and no tracking. All fonts, images and scripts come from this site. The service that hosts the site receives your IP address and basic request data, because it must send the page to you.

The app

The app operates on your computer. It has no account and no telemetry. It sends nothing to us.

  • The installer downloads from GitHub, from the Python Package Index and from Astral (uv). They receive your IP address and apply their own policies.
  • To find updates, the app asks GitHub for the current version from time to time. You can stop this in Settings.
  • The AI model that your helper agents use receives the code that they work on: the API you give a key for, or the provider of Claude Code, Codex, opencode or Antigravity CLI. Your agreement with that provider applies.
  • Report a problem opens a new issue on GitHub in your browser. It sends nothing by itself: you read the report and choose what to post.
  • When you decompile a game with a team, your computer connects directly to the room of the host. The host selects the address, or opens a Cloudflare quick tunnel. We are not in this connection.
