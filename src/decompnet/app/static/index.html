          About this project
          
          
          
            
          
            
          
            
          
              
          Choose your copy of the game again and replace its analysis. Matched C is kept only for functions whose target bytes are unchanged; changed functions reopen. Notes, settings and saved progress are kept. Helpers stop while the game is reimported.
          
              
          
              
          
              
          
            
          
          
          
        
          
        
          
          
          Save your progress
          
          
          
            
          The matched functions are in this project's own source files and git. What's only in decompdecomp is each unmatched function's closest attempt so far (a near miss is often 97–99.9%): Save now writes those as best/<function>.c, each saying how close it is and which source file it belongs in. Handy for a port while matching goes on.
          
            
          decompdecomp saves your work on this game by itself every few minutes, as plain files in the project's progress folder: matched C, notes, names, compiler ranges and settings, never the game itself. Copy that folder (or push it to git) and open it on another computer with New project → Open a saved project.
          
            
            
          
            
          
          
          
        
          
      
          
    
          
    
          
      
          Remove project
          
      
          Matched functions and notes are deleted from decompdecomp. You can keep or delete the project folder.
